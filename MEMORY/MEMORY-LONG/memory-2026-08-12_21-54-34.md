### **Steps to Parse JSON from MQTT Topic Safely**
1. **Include Required Libraries**:  
   Use `PubSubClient` for MQTT and `ArduinoJson` for JSON parsing.  
   - `PubSubClient` for MQTT communication.  
   - `ArduinoJson` for JSON parsing (ensure `StaticJsonDocument` is used for fixed-size memory allocation).

2. **Define JSON Size**:  
   Allocate a fixed-size `StaticJsonDocument` (e.g., `StaticJsonDocument<200>` for 200 bytes). Adjust the size based on your expected JSON payload.

3. **Subscribe to MQTT Topic**:  
   Connect to the MQTT broker and subscribe to the topic.

4. **Parse JSON in Message Callback**:  
   Use `deserializeJson` to parse the incoming payload into the `StaticJsonDocument`.

5. **Access Parsed Data**:  
   Extract values from the JSON document.

6. **Memory Management**:  
   `StaticJsonDocument` automatically frees memory when the object goes out of scope, avoiding leaks.

---

### **Example Code**
```cpp
#include <WiFi.h>
#include <PubSubClient.h>
#include <ArduinoJson.h>

// MQTT and WiFi credentials
const char* ssid = "YOUR_WIFI_SSID";
const char* mqttServer = "MQTT_BROKER_IP";
const int mqttPort = 1883;
const char* mqttUser = "YOUR_USER";
const char* mqttPassword = "YOUR_PASSWORD";

// MQTT client setup
WiFiClient wifiClient;
PubSubClient client(wifiClient);

void setup() {
    Serial.begin(115200);
    WiFi.begin(ssid);
    while (WiFi.status() != WL_CONNECTED) {
        delay(1000);
        Serial.println("Connecting to WiFi...");
    }
    client.setServer(mqttServer, mqttPort);
    client.setCallback(messageReceived);
    while (!client.connect("ESP32Client", mqttUser, mqttPassword)) {
        Serial.println("Connecting to MQTT...");
        delay(5000);
    }
    client.subscribe("sensor/data");
}

void loop() {
    client.loop();
}

void messageReceived(const char* topic, byte* payload, unsigned int length) {
    // Define a fixed-size JSON document (adjust size based on expected payload)
    StaticJsonDocument<200> doc;
    DeserializationError error = deserializeJson(doc, payload, length);

    if (error) {
        Serial.println("Failed to parse JSON: " + String(error.c_str()));
        return;
    }

    // Access parsed data
    float temperature = doc["temperature"];
    int humidity = doc["humidity"];
    Serial.print("Temperature: ");
    Serial.println(temperature);
    Serial.print("Humidity: ");
    Serial.println(humidity);

    // No manual memory management needed - StaticJsonDocument is stack-allocated
}
```

---

### **Key Notes**
- **Memory Safety**:  
  `StaticJsonDocument` uses stack memory, so no manual `delete` is required. The memory is freed when the `doc` object goes out of scope.
- **Error Handling**:  
  Check `deserializeJson` return value to handle parsing errors.
- **Dynamic JSON (Optional)**:  
  If JSON size varies, use `DynamicJsonDocument` with a capacity (e.g., `DynamicJsonDocument<1024>`), but ensure you explicitly delete it after use:
  ```cpp
  DynamicJsonDocument* doc = new DynamicJsonDocument(1024);
  deserializeJson(*doc, payload, length);
  // Process data...
  delete doc;
  ```

---

### **Why This Works**
- **Avoids Memory Leaks**:  
  `StaticJsonDocument` is stack-allocated and does not require heap management.
- **Efficiency**:  
  Fixed-size allocation is faster and safer for embedded systems.
- **Scalability**:  
  Adjust the `StaticJsonDocument` size based on your JSON payload to avoid overflow.

This approach ensures your ESP32 handles JSON parsing safely and efficiently.
